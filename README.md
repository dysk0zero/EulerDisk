Disclaimer: This README.md file covers only bash terminal (Unix OS) and the CLI commands for the python package manager: uv.

## Initialization
To initialize, run in your terminal:
```bash
  uv sync
```

## Usage
Simply create an .ipynb file or use a premade file under /notebooks, importing "data_processing".
Do not edit the files under /src/ unless you know what you are doing.
